# DStat-RD / Recursos Gráficos y Multimedia (Assets)

Este directorio contiene imágenes, fotos, diagramas y recursos visuales del proyecto.

---

## 📂 Organización

- **`photos/`**: Fotografías en alta resolución del instrumento físico ensamblado, PCB y accesorios.
- **`gui/`**: Capturas de pantalla de la interfaz gráfica en funcionamiento, ventanas de configuración y gráficos de barrido.
- **`covers/`**: Banners, imágenes de portada para documentación o repositorios web, y logos.
- **`diagrams/`**: Diagramas de bloques, conexionado de electrodos, esquemas de flujo y arquitectura.
