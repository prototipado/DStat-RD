# DStat-RD / Documentación

Índice central de la documentación técnica y de usuario para DStat-RD.

---

## 📚 Documentos Disponibles

1. **[Manual de Usuario](./user-manual.md)**  
   Guía de operación de la interfaz gráfica, configuración de parámetros y ejecución de experimentos.

2. **[Guía de Montaje y Carcasa](./assembly.md)**  
   Instrucciones paso a paso para el ensamblaje de la placa electrónica, instalación en el gabinete 3D, inserción de insertos roscados y cableado interno.

3. **[Conexión al Instrumento](./connection.md)**  
   Esquema de pines, interfaces de electrodos (Trabajo / Referencia / Contraelectrodo / Auxiliares), conexión USB y masa/tierra.

4. **[Procedimiento de Calibración](./calibration.md)**  
   Guía para la calibración de corrientes, potenciales, resistencias patrón de prueba (dummy cell) y verificación de ganancia.

5. **[Solución de Problemas (Troubleshooting)](./troubleshooting.md)**  
   Diagnóstico de problemas frecuentes de comunicación USB, fallos de alimentación, ruidos electromagnéticos y modo DFU.
