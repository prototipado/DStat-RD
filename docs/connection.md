# Conexión al Instrumento - DStat-RD

Especificaciones de conexionado eléctrico para celda electroquímica y alimentación.

---

## ⚡ Conexión de Electrodos

El equipo soporta configuraciones estándar de 2 y 3 electrodos:

| Terminal | Nombre | Función | Color Recomendado |
| :--- | :--- | :--- | :--- |
| **WE** | Working Electrode | Electrodo de trabajo (medición de corriente) | Rojo |
| **RE** | Reference Electrode | Electrodo de referencia (sensado de potencial) | Azul / Blanco |
| **CE** | Counter / Auxiliary Electrode | Contraelectrodo (inyección de corriente) | Negro |

> **Nota:** Para mediciones de 2 electrodos, cortocircuitar RE con CE.

---

## 🔌 Conexión USB y Alimentación

- Conexión mediante cable USB blindado de buena calidad.
- En entornos con alto ruido electromagnético, se recomienda utilizar un aislador USB o trabajar dentro de una jaula de Faraday para corrientes bajas (pA a nA).
